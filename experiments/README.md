# Experiments

Each experiment folder is intentionally self-contained. Run a script only
after changing MATLAB's current folder to the relevant directory; this
preserves the original scripts' relative paths to CSV inputs and helper
functions.

- [`gamp/`](gamp/) contains standalone GAMP mismatch-rate simulations.
- [`beamforming/`](beamforming/) contains beamforming and channel-prediction
  simulations, CDL inputs, and reusable local helpers.
