# Results

This directory stores figures and numerical outputs retained from prior runs.
They are versioned as research records; do not assume every result was produced
by the current revision until each experiment is rerun and documented.

- `gamp/` contains figures associated with the standalone GAMP experiments.
- `../experiments/beamforming/results/` contains beamforming figures and saved
  MATLAB outputs close to the scripts that generated them.
